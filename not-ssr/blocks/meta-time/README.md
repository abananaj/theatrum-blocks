# Meta Time Block

Display time values from post metadata with flexible formatting options. Parses and formats time meta fields from the current post.

## Key Features

- Configurable time format (12-hour, 24-hour, custom formats)
- Supports various time input formats
- Flexible HTML tag selection (p, span, div, etc.)
- Text color and background color customization
- Typography controls including font size, weight, and line height
