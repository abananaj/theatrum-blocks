This block is a variation of the core/query block that is specific to each post type, including:
1. Production Loop
2. Event Loop
3. Class Loop
4. Blog Loop (for posts, difference in name & icon only, same functionality as core/query)
5. Artist Loop
6. Supporter Loop
7. Credit Loop
8. Venue Loop

Under Settings in the Block editor inspector panel, the "QUERY TYPE" and "POST TYPE" will not be visible as they will be preset. Everything else should be the same.
