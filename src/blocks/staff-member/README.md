# Staff Member Block

Display staff member information from WordPress site options. Similar to Board Member block, this retrieves and displays staff data stored in wp_options.

## Key Features

- Retrieves staff information from WordPress options
- Configurable HTML tag rendering (p, span, a, headings, etc.)
- Optional URL/link support for clickable staff names
- Resolves post IDs to staff post links and titles
- Real-time editor preview via REST endpoint
