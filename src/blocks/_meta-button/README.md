# Meta Button Block

Render a clickable button/link from a URL stored in post metadata. Displays a configurable button that links to a URL from a meta field.

## Key Features

- Retrieves URL from specified post meta key
- Customizable button text
- Full color and typography styling options
- HTML tag selection for link display
- Works with any post type that has meta data

```html

<!-- wp:buttons -->
<div class="wp-block-buttons">
  <!-- wp:button -->
<div class="wp-block-button">
  <a class="wp-block-button__link wp-element-button"></a>
  </div>
<!-- /wp:button --></div>
<!-- /wp:buttons -->

```
